# Échecs 3D — version web (iPad)

Jeu d'échecs 3D contre l'ordinateur (Stockfish 19), installable et jouable hors ligne.

**Installer sur iPad** : ouvrir l'adresse du jeu dans Safari → bouton Partager → « Sur l'écran d'accueil ».
Après le premier chargement, le jeu fonctionne sans connexion. La partie est sauvegardée sur l'appareil.
